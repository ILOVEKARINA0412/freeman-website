# Freeman Cheung — Personal Website

Current desktop and mobile website release, saved 12 November 2026.

## Open the website

- Desktop: open `desktop/index.html`.
- Mobile: open `mobile/index.html`.
- Download `Freeman_Desktop_and_Mobile.zip` and extract the whole archive first.

Keep `desktop/`, `mobile/` and `assets/` together. Each version has separate HTML, CSS and JavaScript files. Shared photos, the embedded Outfit font and the About photo carousel are in `assets/`.

No server, installation or build step is required. The Instagram link requires internet access.

This update contains the website only; it does not include the standalone video previews or video production files. The older standalone HTML files and `001` are retained as earlier versions. Use the `desktop/` and `mobile/` folders for the current website.
