# Freeman Cheung — Personal Website

Latest website update: 20 November 2026.

## Open the website

- Desktop: open `desktop/index.html`.
- Mobile: open `mobile/index.html`.
- Download `Freeman_Desktop_and_Mobile.zip`, extract the entire archive and keep `desktop/`, `mobile/` and `assets/` together.

Each version has separate HTML, CSS and JavaScript files. Shared photos, the embedded Outfit font, About carousel and My Journey card stack are in `assets/`. No installation, build step or server is required. The Instagram link needs internet access.

## My Journey

Three chapters share one animated card stack: My background, My football journey and University life. Select a chapter, use Previous/Next, swipe horizontally, or focus the cards and use arrow keys, Home or End. The stack respects reduced-motion settings and does not advance automatically. Without JavaScript, all three chapters remain readable.

University life includes learning HTML, CSS, JavaScript and Python, and working with AI agents to build websites, write code and debug problems.
